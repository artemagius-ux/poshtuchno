# Поштучно

Учёт трат **по позициям**, а не по категориям. Не «продукты — 4 300 ₽», а «энергетики: 12 банок, 1 428 ₽, средняя цена выросла с 105 до 119 ₽».

## Чем отличается

- **Товар — отдельная сущность** со своей историей цен по магазинам. Видно, как менялась цена конкретной вещи.
- **Теги поверх категорий.** «Энергетики» — не категория (она «Продукты»), а тег. По любому тегу можно смотреть сумму и ставить лимит.
- **Виджеты-счётчики** по произвольному тегу — прямо на домашнем экране.
- **Быстрый ввод.** Открыл, вписал сумму, закрыл. Разбор по позициям — когда есть желание, а не обязательно.

Всё хранится на устройстве. Ни аккаунтов, ни серверов, ни аналитики.

## Статус

P0: каркас проекта, схема данных, экран-скелет, сборка в CI. Приложение пока ничего не умеет.

Дальше: быстрый ввод и работа с базой (P1) → позиции чека и штрихкоды (P2) → QR фискальных чеков (P3) → аналитика и виджеты (P4).

## Стек

Kotlin 2.2.21, Compose Material3 (BOM 2026.06.01), Room 2.8.4, Glance 1.2.0, AGP 8.13.2, Gradle 8.14.4. compileSdk 36, minSdk 29.

## Сборка

```bash
./gradlew assembleDebug
```

Нужен Android SDK и JDK 17. Готовый debug APK лежит в артефактах последней сборки на вкладке Actions.

Суммы внутри хранятся в копейках (`Long`), количество — в тысячных доли единицы. Никаких `Double` для денег.
